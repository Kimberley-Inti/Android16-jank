# 模拟器与 Jank 监测器启动步骤

以下步骤适用于本机 `emu64x` 模拟器和 MUST Jank Monitor。模拟器和桌面监测器需要分别运行在两个终端中。

## 1. 启动模拟器

在第一个终端执行：

```bash
cd /path/to/lineage
bash tools/must-jank-monitor/start-emulator.sh
```

保持这个终端运行。脚本会加载当前编译好的模拟器镜像；如果模拟器已经在线，会提示并退出，不会再启动一个实例。

首次启动或想确认系统已启动时，在第二个终端执行：

```bash
cd /path/to/lineage
out/host/linux-x86/bin/adb -s emulator-5554 shell getprop sys.boot_completed
```

输出 `1` 表示 Android 已启动。也可以查看监测服务状态：

```bash
out/host/linux-x86/bin/adb -s emulator-5554 shell cmd must_jank status
```

## 2. 启动桌面监测器

在另一个终端执行：

```bash
cd /path/to/lineage
export PATH="$PWD/out/host/linux-x86/bin:$PATH"
/usr/bin/python3 tools/must-jank-monitor/main.py
```

在窗口中选择 `emulator-5554`，点击 **START MONITOR**。监测开始后可以打开、滚动或切换任意 App；监测不绑定某一个 App。完成后点击 **STOP MONITOR**，程序会结束采集并保存结果。

## 3. 安装 Tkinter（仅在提示缺少 tkinter 时）

```bash
sudo apt install python3-tk
```

安装完成后重新运行上面的桌面监测器命令。监测器不需要额外的 Python pip 包。

## 4. 查看采集结果

每次采集保存在：

```text
tools/must-jank-monitor/sessions/<日期>_<设备>/
```

主要文件包括 `session.json`（会话信息和汇总）、`jank.jsonl`（FrameTimeline Jank 事件）、`scenes.jsonl`（场景区间）、`correlated_jank.jsonl`（关联场景后的 Jank 事件）、`stats.jsonl`（帧统计）和 `raw.log`（原始日志）。

## 常见情况

- `getprop sys.boot_completed` 还没有输出 `1`：模拟器仍在启动，等一会再查。
- ADB 显示 `offline`：等模拟器完成启动后重查；如果仍为 offline，查看启动终端输出的 `boot-*.log`。
- `cmd must_jank` 找不到：当前模拟器镜像没有运行带监测服务的构建，先确认启动脚本使用的是项目的 `out/target/product/emu64x` 镜像。
- 监测窗口提示没有设备：确认模拟器已启动，并检查 `adb devices -l` 中 `emulator-5554` 状态为 `device`。
